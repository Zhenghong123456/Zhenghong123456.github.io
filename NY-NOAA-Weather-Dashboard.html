NY NOAA Weather Dashboard

ny_noaa_temperature = ny_noaa_2010 |>
  mutate( tmax = as.numeric(tmax), tmin = as.numeric(tmin)) |>
  drop_na(tmax, tmin) |>
  filter(tmax >= tmin) |>
  mutate( tmax_c = tmax / 10, tmin_c = tmin / 10, month = factor(lubridate::floor_date(date, unit = "month")))
ny_noaa_precipitation = ny_noaa_2010 |>
  drop_na(prcp) |>
  mutate( month = lubridate::floor_date(date, unit = "month"), prcp_mm = prcp / 10) |>
  group_by(month) |>
  summarize(mean_prcp_mm = mean(prcp_mm))

Minimum vs. Maximum Temperature in January 2010

This scatterplot compares daily minimum and maximum temperatures in January 2010. Each point represents one weather station observation. Temperatures are in degrees Celsius.

weather_scatter = ny_noaa_temperature |>
  filter(date < "2010-02-01") |>
  ggplot(aes(x = tmin_c, y = tmax_c)) +
  geom_point(alpha = 0.5) +
  labs( x = "Minimum temperature (C)", y = "Maximum temperature (C)")

ggplotly(weather_scatter)
